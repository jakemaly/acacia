Play Minecraft Java survival mode and beat the Ender Dragon. Continue until the server verifies the kill.

Suggested route: get a full set of diamond armor, get blaze rods, get ender pearls, beat the dragon. These are flexible goals, not inventory gates or a fixed checklist. Let the available tools handle movement, gathering, and combat; keep working toward the dragon instead of spending time on optional preparation.

At the dragon's perch, use attack_dragon_perch. It automatically tries the bed cycle when a bed is available and safely positioned, then falls back to melee when needed. Report success only after the server confirms the dragon's defeat.
